# Stocks
Real-Time Stock Price Tracker (2025)

Developed a Python-based stock price tracker using the Yahoo Finance (yfinance) library to fetch and display the latest stock prices of different companies. The project allows users to enter stock symbols such as AAPL or MSFT and view the most recent market price in a simple and user-friendly format.

The program also includes error handling to manage invalid stock symbols or unavailable data effectively. While building the project, applied core Python concepts such as variables, functions, user input, conditional statements, exception handling, object creation, indexing, and formatted output.
Through this project, I gained practical exposure to financial data analysis and improved my understanding of Python programming and external libraries.
